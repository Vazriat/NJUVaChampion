## v2.0 相对 v1.0 的变化

### 1. 赛事直播

裁判在「设置 → 我的直播间」绑定一次 B 站直播间，之后每场比赛在详情弹窗点「开始直播」即可。观众在 `/live` 和比赛弹窗里直接观看，**无广告、无弹幕窗**，1080p。

- **只有 B 站能站内播放**。虎牙/斗鱼/抖音没有等价的嵌入页，只做跳转卡片，且会明确标注「站外播放」
- **B 站短号会自动转换**。`live.bilibili.com/6` 存进去是短号，直接用会黑屏（连 `<video>` 元素都不创建），系统在绑定时调 B 站接口换成真实 `room_id`（`7734200`）
- **开播确认框会显示直播间当前标题**，裁判能当场发现房间号填错、或者 B 站那边还没开播
- **一场同时只能有一路直播**，由数据库唯一索引保证，不是靠前端拦
- 比赛完结时自动关播；裁判忘记关的，6 小时后自动清理
- 管理端可隐藏某个直播间、强制结束某场直播

### 2. 赛事视频（回放 / 精彩集锦）

原来的「回放」只是一串文字链接，现在升级成视频模块：

- **只存链接，不存文件**。视频托管在 B 站，站内不承担存储与带宽（2C4G 的机器扛不住视频流量）
- **提交 B 站链接自动读取标题、封面、时长**，封面在卡片上直接展示
- **上传权限**：该场比赛的参赛队员、认证裁判、管理员——选手终于能传自己的集锦了
- **分类**：赛事回放 / 精彩集锦 / 其他
- **两个入口**：比赛详情弹窗（比赛自动确定）、赛事页「视频 / 回放 →」（下拉选比赛）
- **B 站视频支持站内弹层播放**，其他平台新窗口跳转

### 3. 人才市场

- 发布招募（战队招人）与求职（个人找队）帖子
- 入队申请与邀请：申请人 / 队长双向发起，对方接受或拒绝
- 管理员可下架违规帖子并通知作者
- 配套「定向消息」：入队申请、审核结果等直接推给本人，导航栏有未读数

### 4. 修复：生涯统计被 `-1` 静默拉低

OCR 曾用 `-1` 表示「该字段没识别出来」。这些值被当成真实数据参与求和平均，把 ACS、首杀率等指标整体拉低（历史数据里 firstBlood 有 15/30 条是 `-1`）。现在：

- 写入侧归一化为 `null`，后端落库前再兜底一次
- 读取侧**每项指标各自统计有效场次与有效回合**，不再共用一个分母

同时统一了特工（英雄）清单的唯一来源，避免三处各写一份；OCR 失败时的语义也从「返回空数据」改为明确报错。

### 5. 工程与文档

- 新增 `docs/live-module.md`（直播模块设计与取舍）、`docs/talent-market-design.md`
- `AGENTS.md` 增加 3 条实测踩坑：B 站短号黑屏、iframe 只能拼 roomId（禁止用用户填的链接，否则等于开放站内任意页面渲染）、B 站图片防盗链（外站 Referer 一律 403）
- 全站确认弹窗统一，移除浏览器原生 `confirm` / `alert`
- 修复 `deploy.sh` 镜像对齐核对的误报，并让镜像漂移能就地自愈

## 技术要点（面向开发）

| 场景 | 做法 |
|---|---|
| B 站直播嵌入 | 官方活动页播放器 `blackboard/live/live-activity-player.html?cid={roomId}`，实测无 `X-Frame-Options`，1080p 无广告 |
| B 站视频嵌入 | `player.bilibili.com/player.html?bvid={bvid}`，bvid 先正则校验再拼 src |
| 短号转换 | `api.live.bilibili.com/room/v1/Room/get_info`，**不能带 `Origin` 头**（带了直接 403） |
| 视频元数据 | `api.bilibili.com/x/web-interface/view?bvid=`，取 title / pic / duration |
| 封面防盗链 | B 站图片外站 Referer 一律 403，`<img>` 必须加 `referrerPolicy="no-referrer"` |
| 直播并发控制 | `live_streams.active_key` 唯一索引（LIVE 时= matchId，否则 NULL），MySQL 允许多个 NULL |
| 出站安全 | 短链跟随仅白名单域名、最多 3 跳、5s 超时；iframe src 一律模板拼接，绝不用用户填的 URL |

数据库表：**18 → 24 张**（新增 `referee_channels`、`live_streams`、`match_videos`、`recruitment_posts`、`team_applications`、`user_notifications`）。

## 注意事项 / 已知限制

1. **直播与视频都依赖服务器访问 B 站接口**。已实测生产服务器（含 backend 容器）可正常访问；若更换服务器或网络策略变更，需重新验证，否则绑定直播间会提示「暂时无法校验该直播间」、视频封面为空
2. **只有 B 站能在站内播放**。虎牙/斗鱼/抖音只做跳转；如果以后要支持，需要各自找嵌入方案，成本不低
3. **视频上传的是链接，不是文件**。这是刻意的：2C4G 的磁盘、带宽和转码能力都撑不住视频流量
4. **未绑定直播间的裁判开播会失败**。工作台和比赛页都会引导去设置页绑定，不会静默失败
5. **B 站接口属于非公开 API**，没有稳定性承诺。已做降级：抓不到元数据时视频仍可提交，只是没有封面；直播绑定失败会明确报错而不是存个坏数据
6. **违规内容处理**：视频由参赛队员自行提交，管理端提供下架（`HIDDEN`）；直播间同样可隐藏
